    🛡️ About ShieldAI

    ShieldAI is a real-time payment fraud detection prototype built for a hackathon. It combines two ML models with a customer-context layer to minimize false alerts while catching genuine fraud.

    🌲

    Random Forest

    150-tree ensemble classifier trained on 300k PaySim transactions. Uses balanced_subsample to handle extreme class imbalance (~99.8% legit).

    🔬

    Isolation Forest

    Anomaly detector trained on legitimate transactions only. Catches novel fraud patterns the RF hasn't seen before.

    👤

    Customer Context

    Checks if the transaction fits the customer's historical behaviour. Reduces false alerts for genuine high-value customers.

    ⚡

    4-Tier Decisions

    HIGH RISK → MEDIUM RISK → LOW RISK (Context Match) → LOW RISK. The HIGH tier can never be overridden by customer context.

    Decision Logic

    ≥ 80% probability → 🔴 HIGH RISK
    Context CANNOT override
    ↓
    ≥ 30% prob OR anomaly → 🟡 MEDIUM RISK
    Unless customer context clears it
    ↓
    Normal customer pattern → 🔵 LOW RISK - CONTEXT MATCH
    Amount ≤ 1.5× avg + familiar pattern
    ↓
    All clear → 🟢 LOW RISK
    Approve transaction

    Features Used (No Data Leakage)

    step amount oldbalanceOrg oldbalanceDest type_PAYMENT type_TRANSFER type_CASH_OUT type_CASH_IN type_DEBIT ❌ newbalanceOrig ❌ newbalanceDest

    ⚠️ Limitations

    • PaySim is synthetic data — real fraud is messier and adversarial
    • "Real-time" simulation is a demo — no Kafka or streaming pipeline
    • Customer context is computed offline, not from a live profile store
    • No concept drift detection — model needs periodic retraining
    • Single-machine, in-memory — not horizontally scalable

    🔌 API Endpoints

    GET /health — Model status
    POST /predict — Score one transaction
    POST /simulate — Batch random scoring
    GET /history — Transaction history
    GET /stats — Aggregate stats
    GET /api/docs — Swagger UI
